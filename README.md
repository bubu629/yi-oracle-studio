厌倦了市面上满屏弹窗广告、动辄按次收费、断网就打不开的算命 App？

## ✨ 核心功能一览

* **🪙 周易六爻 · 金钱起卦**
  * 支持逐爻摇卦与一键六爻成卦，自动绘出本卦、动爻与变卦[cite: 6]。
  * 内置《周易》全量 64 卦典籍库：涵盖**卦辞原文、《大象传》、白话精解**，以及**事业、财运、感情、动爻演变**四维离线详批[cite: 6]。
* **🌸 梅花易数 · 真农历排盘**
  * 自动调用权威农历与地支序数起卦，也支持报数起卦[cite: 6]。
  * 自动排布本卦、互卦、变卦，精准判定**体用五行生克**，并内置先天八卦**万物类象与离线应期参考**[cite: 6]。
* **📜 铁板神数 · 12,000 条离线条文库 + 节气八字**
  * 集成 MIT 开源权威历法库 `lunar-javascript`，离线精准排布**二十四节气四柱八字、五行旺衰、纳音、十神、胎元、命宫、身宫与大运**[cite: 6, 7]。
  * 内置 **12,000 条《铁板神数》离线条文库**（子集～亥集，编号 `1001`～`13000`），支持生辰考刻六维推演与**条文号直查**[cite: 7]。
  * 内置十天干日主详批与五行调候建议，顶部实时展示**今日黄历宜忌与财神方位**[cite: 6]。
* **🤖 （可选）AI 大师深度解盘**
  * 不填 API Key 即可离线使用全部排盘与详批功能[cite: 6]。
  * 填入个人 Gemini API Key 后，可结合具体所问之事输出定制断语，内置多模型自动切换防限流机制[cite: 6]。
